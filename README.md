# Revanth Kumar Narra - Colorful Data Engineering Portfolio

This is a recruiter-focused, colorful static portfolio built with HTML and CSS.

## Files

- `index.html` - Main portfolio page
- `style.css` - Colorful responsive styling
- `resume.docx` - Resume file
- `assets/cloud-lakehouse-architecture.svg` - Project architecture diagram
- `assets/unstructured-pipeline.svg` - Project architecture diagram

## Before Deploying

Edit `index.html` and replace all placeholder links.

Search for:

```html
href="#"
```

Replace those with your real:

- LinkedIn URL
- GitHub URL
- Cloud Lakehouse project GitHub repo
- Unstructured Pipeline project GitHub repo

## Netlify Settings

Use:

- Build command: leave empty
- Publish directory: .

Do not type "leave blank" into the build command field. Empty means empty, not a philosophical instruction to Netlify.

## Recommended Site Name

`revanth-data-engineer`
