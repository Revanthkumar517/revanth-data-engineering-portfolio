# Revanth Kumar Narra - Data Engineering Portfolio

This is a static HTML/CSS portfolio for Data Engineering roles.

## Files

- `index.html` - Main portfolio page
- `style.css` - Styling and responsive layout
- `resume.docx` - Resume file
- `assets/cloud-lakehouse-architecture.svg` - Project architecture diagram
- `assets/unstructured-pipeline.svg` - Project architecture diagram

## Before Deploying

Edit `index.html` and replace these placeholders:

- LinkedIn link
- GitHub link
- Project GitHub repository links
- Portfolio/resume link if needed

Search for:

```html
href="#"
```

Replace each `#` with the correct URL.

## Netlify Deployment Settings

Use these settings:

- Build command: leave blank
- Publish directory: .
